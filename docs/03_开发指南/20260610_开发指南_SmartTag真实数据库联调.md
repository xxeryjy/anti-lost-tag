# SmartTag 真实数据库联调指南

## 目标

将后端从默认 mock 数据源切换到 Prisma + MySQL，用真实数据库验证认证、主人端标签列表等接口。

## 环境变量

复制 `.env.example` 为 `.env`，并至少确认以下变量：

```env
API_DATA_SOURCE=database
DATABASE_URL=mysql://root:password@127.0.0.1:3306/smarttag
SESSION_SECRET=dev-session-secret
AUTH_MOCK_CODE=123456
AUTH_ENABLE_EMAIL_VENDOR=false
AUTH_CODE_EXPIRES_MINUTES=10
MAIL_PROVIDER=none
MAIL_FROM="SmartTag <no-reply@example.com>"
MAIL_API_KEY=
UPLOAD_MAX_IMAGE_SIZE_BYTES=5242880
PUBLIC_SCAN_RATE_LIMIT_MAX=60
PUBLIC_SCAN_RATE_LIMIT_WINDOW_MS=60000
PUBLIC_MESSAGE_RATE_LIMIT_MAX=10
PUBLIC_MESSAGE_RATE_LIMIT_WINDOW_MS=300000
UPLOAD_IMAGE_RATE_LIMIT_MAX=20
UPLOAD_IMAGE_RATE_LIMIT_WINDOW_MS=3600000
```

- `API_DATA_SOURCE=mock`：继续使用内存 mock 数据，适合前端快速开发。
- `API_DATA_SOURCE=database`：使用 Prisma 访问 MySQL。
- `AUTH_MOCK_CODE`：未启用真实邮件供应商时，会作为开发验证码写入数据库验证码表。
- `AUTH_ENABLE_EMAIL_VENDOR=false`：不真实发信，接口返回 `mockMode=true`。
- `AUTH_ENABLE_EMAIL_VENDOR=true`：启用真实邮件供应商，并生成 6 位随机验证码。
- `AUTH_CODE_EXPIRES_MINUTES`：邮箱验证和密码重置验证码有效期，默认 10 分钟。
- `MAIL_PROVIDER=none`：不发送邮件；`console` 会把邮件内容打印到服务端日志；`resend` 会调用 Resend API。
- `MAIL_FROM` / `MAIL_API_KEY`：真实邮件供应商发信配置。
- `UPLOAD_MAX_IMAGE_SIZE_BYTES`：图片上传大小上限，默认 `5MB`。
- `PUBLIC_SCAN_RATE_LIMIT_*`：公开扫码接口的 IP 级基础防刷配置。
- `PUBLIC_MESSAGE_RATE_LIMIT_*`：匿名留言接口的 IP 级基础防刷配置；真实数据库模式下还会按 `tagId + ipAddress` 做 5 分钟业务限流。
- `UPLOAD_IMAGE_RATE_LIMIT_*`：登录用户上传图片的 IP 级基础防刷配置。

生产环境额外要求：

- `API_DATA_SOURCE` 必须配置为 `database`，否则接口会拒绝继续使用 mock 数据源。
- `SESSION_SECRET` 必须替换为至少 32 位的非默认密钥。
- 如果 `AUTH_ENABLE_EMAIL_VENDOR=true`，必须配置可用的 `MAIL_PROVIDER`、`MAIL_FROM` 和对应密钥。

## 初始化命令

```bash
yarn prisma:generate
yarn db:push
yarn db:seed
```

`yarn db:push` 会把 `prisma/schema.prisma` 同步到当前 `DATABASE_URL` 指向的数据库。

`yarn db:seed` 会写入演示数据：

## 生产化补强口径

当前已落地的最小生产化保护：

- Session Cookie 使用签名值，生产环境禁止默认短密钥。
- 生产环境禁止继续使用 `API_DATA_SOURCE=mock`。
- 真实数据库模式下，邮箱验证和密码重置验证码会写入 `AuthCode` 表，验证码只保存哈希，成功使用后会标记为已消费。
- 邮件服务已支持 `none`、`console`、`resend`；生产建议使用 `resend` 或继续扩展 SMTP/SES。
- 扫码通知和匿名留言通知会根据邮件发送结果更新 `notificationStatus` / `deliveryStatus`。
- 公开扫码、匿名留言、图片上传增加内存限流，并返回 `RATE_LIMITED` 与 `Retry-After`。
- 上传接口校验真实图片文件头，不能只依赖浏览器上报的 MIME。
- 本地上传文件保存到 `storage/uploads/images`，返回 `/api/uploads/image/:filename` 供同源访问。

后续正式上线前建议继续补：

- 将内存限流迁移到 Redis，避免多实例部署时限流失效。
- 将本地上传迁移到 R2/S3 等对象存储，并补删除/清理策略。
- 将内存验证码/通知限流、邮件发送失败重试和审计日志继续生产化。
- 使用 Prisma migration 流程管理生产数据库变更，不使用 `db push` 直推生产库。
