## 2. 通用约定

### 2.1 Base URL

```text
/api
```

### 2.2 鉴权约定

- Finder 公开接口默认匿名访问。
- 主人端管理接口需要登录态。
- 登录态建议使用 HttpOnly Cookie Session。

### 2.3 统一响应结构

成功响应：

```json
{
  "success": true,
  "data": {}
}
```

失败响应：

```json
{
  "success": false,
  "error": {
    "code": "INVALID_PARAMS",
    "message": "参数错误"
  }
}
```

### 2.4 通用错误码

| 错误码 | 说明 |
|------|------|
| `INVALID_PARAMS` | 参数错误 |
| `UNAUTHORIZED` | 未登录或登录失效 |
| `FORBIDDEN` | 无权限访问 |
| `NOT_FOUND` | 资源不存在 |
| `TAG_ALREADY_BOUND` | 标签已绑定 |
| `INVALID_ACTIVATION_CODE` | 激活码错误 |
| `RATE_LIMITED` | 请求过于频繁 |
| `INTERNAL_ERROR` | 服务器内部错误 |

## 4. 标签与激活接口

### 4.1 激活标签

`POST /api/tags/activate`

用途：

- 校验二维码 `uid`
- 校验包装上的 `activationCode`
- 把标签绑定到当前登录用户

请求体：

```json
{
  "uid": "Ax9z",
  "activationCode": "A1B2C3D4"
}
```

响应体：

```json
{
  "success": true,
  "data": {
    "tag": {
      "id": 1,
      "uid": "Ax9z",
      "status": "ACTIVE"
    }
  }
}
```

错误补充：

| 错误码 | 说明 |
|------|------|
| `TAG_ALREADY_BOUND` | 标签已被其他用户绑定 |
| `INVALID_ACTIVATION_CODE` | 激活码错误 |

### 4.2 更新标签状态

`PATCH /api/tags/:id/status`

用途：

- 主人切换 `ACTIVE / LOST`

请求体：

```json
{
  "status": "LOST",
  "rewardText": "Reward available"
}
```

响应体：

```json
{
  "success": true,
  "data": {
    "tag": {
      "id": 1,
      "status": "LOST",
      "rewardText": "Reward available"
    }
  }
}
```

## 6. Finder 公开接口

### 6.1 获取公开资料

`GET /api/tags/public/:uid`

用途：

- Finder 打开二维码时获取公开展示数据
- 根据 `privacyMode` 决定是否返回电话

响应体示例一：Direct Contact

```json
{
  "success": true,
  "data": {
    "tag": {
      "uid": "Ax9z",
      "status": "LOST",
      "rewardText": null
    },
    "profile": {
      "category": "PET",
      "petKind": "DOG",
      "displayName": "Luna",
      "photoUrl": "https://cdn.example.com/luna.jpg",
      "medicalNote": "Needs meds daily",
      "hasMicrochip": true,
      "microchipCode": "MC-8899",
      "privacyMode": false,
      "ownerPhone": "13800000000",
      "canSendMessage": false
    }
  }
}
```

响应体示例二：Privacy Mode

```json
{
  "success": true,
  "data": {
    "tag": {
      "uid": "Ax9z",
      "status": "ACTIVE"
    },
    "profile": {
      "category": "ITEM",
      "displayName": "Travel Backpack",
      "photoUrl": null,
      "medicalNote": null,
      "privacyMode": true,
      "ownerPhone": null,
      "canSendMessage": true
    }
  }
}
```

### 6.2 记录扫描日志

`POST /api/tags/public/:uid/scan`

用途：

- 记录 Finder 扫码
- 保存 GPS 或 IP 推断位置
- 触发扫描提醒邮件

请求体：

```json
{
  "latitude": 35.6804,
  "longitude": 139.769,
  "locationSource": "GPS",
  "locale": "ja"
}
```

IP 兜底场景请求体：

```json
{
  "locationSource": "IP",
  "locale": "en"
}
```

响应体：

```json
{
  "success": true,
  "data": {
    "scanLogId": 101,
    "notificationSuppressed": false,
    "mapUrl": "https://maps.google.com/?q=35.6804,139.769"
  }
}
```

### 6.3 提交匿名留言

`POST /api/tags/public/:uid/message`

用途：

- 仅用于 `privacyMode = true`
- 将 Finder 留言匿名转发给主人

请求体：

```json
{
  "scanLogId": 101,
  "finderName": "Sato",
  "finderContact": "sato@example.com",
  "message": "I found your bag near the station."
}
```

响应体：

```json
{
  "success": true,
  "data": {
    "messageId": 1001,
    "deliveryStatus": "PENDING"
  }
}
```

错误补充：

| 错误码 | 说明 |
|------|------|
| `FORBIDDEN` | 当前标签未开启隐私留言 |
| `RATE_LIMITED` | 留言过于频繁 |

## 7. 图片上传接口

### 7.1 上传图片

`POST /api/uploads/image`

用途：

- 主人上传宠物或物品图片

请求方式：

- `multipart/form-data`

响应体：

```json
{
  "success": true,
  "data": {
    "url": "https://cdn.example.com/tag-profile/abc123.jpg"
  }
}
```

约束：

- 支持 `jpg/png/webp`
- 最大 `5MB`

## 8. 服务端处理建议

### 8.1 扫描接口处理顺序

1. 校验 `uid`
2. 获取标签与公开资料
3. 解析 GPS 或 IP
4. 生成 `mapUrl`
5. 检查 Redis 去重
6. 落库 `ScanLog`
7. 异步发送邮件

### 8.2 留言接口处理顺序

1. 校验 `uid`
2. 校验标签是否 `privacyMode = true`
3. 检查频率限制
4. 落库 `PrivacyMessage`
5. 发送匿名转发邮件
