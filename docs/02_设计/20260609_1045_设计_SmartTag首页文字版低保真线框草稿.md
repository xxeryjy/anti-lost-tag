# SmartTag 首页文字版低保真线框草稿

## 1. 文档目的

本文档用于在不输出代码、不进入高保真视觉稿的前提下，直接用文字线框方式描述 SmartTag 首页在桌面端与移动端的大致结构，帮助以下角色快速对齐：

1. 设计师可按此继续绘制低保真原型
2. 产品可据此确认页面节奏与内容层级
3. 前端可据此开始理解界面骨架与区块关系

## 2. 页面结构总览

首页采用 5 个核心区块，顺序如下：

1. `Nav + Hero`
2. `Manifesto`
3. `Story Video`
4. `Mission + Values`
5. `Our Story + Footer`

整体方向保持：

1. 简约
2. 紧凑
3. 品牌展示优先
4. 少按钮
5. 少说明型模块

## 3. 桌面端文字线框

### 3.1 第一屏：Nav + Hero

```text
+--------------------------------------------------------------------------------------------------+
| Logo / Brand                Story        Mission        Values            Lang        Light CTA   |
|                                                                                                  |
|                                                                                                  |
|   [Eyebrow]                                                                                      |
|   [Main Heading, 1-2 lines]                                                                      |
|   [Short Subheading, 1-2 lines]                                                                  |
|   [One Light Button]                                                                             |
|                                                                                                  |
|                                                              [Banner Main Visual]               |
|                                                              [Dog / Running / Brand Mood]       |
|                                                                                                  |
|                      [Scroll Hint]                                                               |
+--------------------------------------------------------------------------------------------------+
```

说明：

1. `nav` 与 Hero 处于同一视觉场
2. 左侧是简短文案区，右侧是保留 banner 的主视觉区
3. 文案区不能太宽，避免首屏被文字填满
4. 右上角语言切换可做轻量 dropdown
5. 主导航不做 dropdown

### 3.2 第二屏：Manifesto

```text
+--------------------------------------------------------------------------------------------------+
|                                                                                                  |
|                               [Eyebrow]                                                          |
|                               [Heading, 1 line]                                                  |
|                                                                                                  |
|                               [Body Paragraph 01]                                                |
|                                                                                                  |
|                               [Body Paragraph 02]                                                |
|                                                                                                  |
+--------------------------------------------------------------------------------------------------+
```

说明：

1. 这是一个很安静的单栏区块
2. 不插图，不加辅助卡片
3. 重点是控制文字宽度和上下留白

### 3.3 第三屏：Story Video

```text
+--------------------------------------------------------------------------------------------------+
|                                                                                                  |
|                           +--------------------------------------------------+                   |
|                           |                                                  |                   |
|                           |                  Video Cover                     |                   |
|                           |                 [Play Button]                    |                   |
|                           |                                                  |                   |
|                           +--------------------------------------------------+                   |
|                                     [One Short Meta Line]                    |
|                                                                                                  |
+--------------------------------------------------------------------------------------------------+
```

说明：

1. 整屏只有一个主视频封面卡片
2. 不做左右图文结构
3. 文案降到最少，让页面节奏停下来

### 3.4 第四屏：Mission + Values

```text
+--------------------------------------------------------------------------------------------------+
| [Eyebrow]                                                                                        |
|                                                                                                  |
|   +--------------------------------------+    +----------------------------------------------+   |
|   | [Heading]                            |    | [Value 01 Title]                              |   |
|   |                                      |    | [Value 01 Short Copy]                         |   |
|   | [Body Paragraph]                     |    |                                              |   |
|   |                                      |    | [Value 02 Title]                              |   |
|   |                                      |    | [Value 02 Short Copy]                         |   |
|   |                                      |    |                                              |   |
|   |                                      |    | [Value 03 Title]                              |   |
|   |                                      |    | [Value 03 Short Copy]                         |   |
|   +--------------------------------------+    +----------------------------------------------+   |
|                                                                                                  |
+--------------------------------------------------------------------------------------------------+
```

说明：

1. 这是全页唯一一个明显带结构感的信息区
2. 左边偏品牌陈述，右边偏价值列表
3. 右栏只保留 3 条，不继续扩展
4. 不要做成三张独立大卡片

### 3.5 第五屏：Our Story + Footer

```text
+--------------------------------------------------------------------------------------------------+
|                                                                                                  |
|                               [Eyebrow]                                                          |
|                               [Heading]                                                          |
|                                                                                                  |
|                               [Body Paragraph 01]                                                |
|                                                                                                  |
|                               [Body Paragraph 02]                                                |
|                                                                                                  |
|                               [Closing Statement]                                                |
|                                                                                                  |
|--------------------------------------------------------------------------------------------------|
| Brand / Logo                     Email / Social / Language / Copyright                           |
+--------------------------------------------------------------------------------------------------+
```

说明：

1. 这一屏负责温和收尾
2. Footer 紧接正文，不要再做一个重模块
3. 最后一屏仍要保持克制，不做强销售 CTA

## 4. 桌面端导航状态草稿

### 4.1 首屏透明态

```text
+--------------------------------------------------------------------------------------------------+
| Logo / Brand                Story        Mission        Values            Lang        Light CTA   |
+--------------------------------------------------------------------------------------------------+
```

说明：

1. 叠在 banner 上
2. 背景透明
3. 整体更轻

### 4.2 滚动后 sticky 态

```text
+--------------------------------------------------------------------------------------------------+
| Logo / Brand                Story        Mission        Values            Lang        Light CTA   |
+--------------------------------------------------------------------------------------------------+
```

说明：

1. 变为浅底或柔和底色
2. 保持原有内容位置，不发生明显跳位
3. 高度维持紧凑，不要变厚

## 5. 移动端文字线框

### 5.1 第一屏：Nav + Hero

```text
+----------------------------------------------+
| Logo / Brand                      [Menu]     |
|                                              |
| [Eyebrow]                                    |
| [Main Heading, 2-3 short lines]              |
| [Short Subheading]                           |
| [Optional Light Button]                      |
|                                              |
|            [Banner Main Visual]              |
|            [Vertical Crop Area]              |
|                                              |
|              [Scroll Hint]                   |
+----------------------------------------------+
```

说明：

1. 移动端首屏高度比桌面端更短
2. 文案要进一步压缩
3. banner 保留，但裁切更聚焦主体

### 5.2 移动端菜单展开态

```text
+----------------------------------------------+
| Logo / Brand                        [Close]  |
|----------------------------------------------|
| Story                                        |
| Mission                                      |
| Values                                       |
|----------------------------------------------|
| Language Switcher                            |
| Light CTA                                    |
+----------------------------------------------+
```

说明：

1. 单层菜单
2. 不做多级展开
3. 语言切换放在菜单工具区

### 5.3 第二屏：Manifesto

```text
+----------------------------------------------+
```

说明：

### 5.4 第三屏：Story Video

2. 保持简洁，不要塞太多链接

## 6. 原型出稿时必须确认的点

设计师在出稿时，至少要把以下问题画清楚：

1. `nav` 首屏态和滚动态的区别
2. Hero 文案和 banner 主体的安全区
3. 桌面端与移动端首屏高度差异
4. 视频卡片的宽高比
5. Mission 区块左右比例
6. Footer 在移动端的折叠方式

## 7. 对开发的价值

这份文字版低保真线框草稿已经足够支持前端开始做以下工作：

1. 首页基础分区结构
2. 锚点导航关系
3. 桌面端 / 移动端响应式容器
4. Header 的两种状态骨架
5. 各区块的文案与媒体占位

但以下内容仍建议等轻量视觉稿再收口：

1. 字体与字号精修
2. 精准间距 token
3. 按钮视觉样式
4. 颜色与层次细节
5. hover 和滚动动效
