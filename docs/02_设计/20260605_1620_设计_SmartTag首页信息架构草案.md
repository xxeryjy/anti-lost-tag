# SmartTag 首页信息架构草案

> 优先级：高
> 创建时间：2026-06-05 16:20
> 修改时间：2026-06-05 16:20
> 创建人：Codex

## 1. 文档目标

本文档用于冻结 SmartTag 首页 `/` 的首版信息架构与文案方向。

当前明确约定：

1. 首页结构直接参考 [Meouwow 官网](https://meouwow.com/)
2. 但品牌内容、文案主题与场景表达替换为 SmartTag 的“防丢找回”
3. 首版需要支持 `zh-CN / en / ja`

## 2. 首页定位

首页不是管理后台，也不是 Finder 页。

首页承担的职责是：

1. 传达品牌气质
2. 解释产品机制
3. 建立信任感
4. 承接登录、注册与扫码激活入口

## 3. 参考结构

参考 `Meouwow` 首页，SmartTag 首页建议按以下区块组织：

1. Hero 首屏
2. Manifesto 品牌宣言
3. Mission / Vision
4. Core Values
5. 产品机制说明
6. 找回场景展示
7. 隐私与安心说明
8. 品牌故事
9. FAQ
10. Footer

## 4. 首页区块草案

### 4.1 Hero 首屏

目标：

1. 一眼说清楚产品是什么
2. 给出主要操作入口

建议文案方向：

- 标题：让每一次走失，都更容易回家
- 副标题：扫码即可查看绑定信息，帮助宠物或物品更快被找回
- 主按钮：立即激活
- 次按钮：了解如何使用

### 4.2 Manifesto 品牌宣言

目标：

1. 建立品牌情绪价值
2. 表达“找回、安心、连接”的品牌基调

建议文案方向：

- 不是每一次丢失都能避免，但每一次寻找都不该毫无方向。
- SmartTag 希望把陌生人的善意，变成更高效的找回路径。

### 4.3 Mission / Vision

目标：

1. 表达产品长期方向

建议内容：

- Mission：让宠物与重要物品的找回更简单
- Vision：让每一块防丢牌都成为连接失主与帮助者的桥梁

### 4.4 Core Values

建议展示 3 到 4 项：

1. Fast Recovery
   - 扫码即见信息，减少沟通成本
2. Privacy First
   - 支持隐私模式，不强制公开真实联系方式
3. Simple by Default
   - 不需要下载 App，打开网页即可使用
4. Trust Through Clarity
   - 信息清晰、状态明确、路径可追踪

### 4.5 产品机制说明

目标：

1. 用最短路径讲明白产品怎么用

建议三步式：

1. 主人扫码激活并绑定信息
2. 发现者扫码查看公开资料
3. 主人收到扫描记录并快速响应

### 4.6 找回场景展示

建议展示两个典型场景：

1. 宠物走失
2. 背包、钥匙、行李等物品遗失

每个场景展示：

1. 发现者看到什么
2. 主人能收到什么
3. 为什么比传统名牌更高效

### 4.7 隐私与安心说明

建议重点解释：

1. 可开启隐私模式
2. Finder 页只显示允许公开的信息
3. 丢失模式会展示红色求助横幅
4. 扫码记录会进入主人端后台

### 4.8 品牌故事

建议内容方向：

1. 为什么做 SmartTag
2. 我们希望解决什么焦虑
3. 为什么强调“简单”和“安心”

### 4.9 FAQ

建议首版至少包含：

1. 需要下载 App 吗
2. 支持哪些语言
3. 一个人可以绑定几个防丢牌
4. 隐私模式是什么意思
5. 丢失模式开启后会发生什么
6. 发现者能看到我的真实电话吗

### 4.10 Footer

建议包含：

1. 品牌名
2. 多语言切换
3. 登录 / 注册 / 激活入口
4. 法务与隐私入口

## 5. 多语言建议

### 5.1 首版策略

建议：

1. 中文先定稿
2. 英文与日文先出直译版
3. 后续再做品牌化润色

### 5.2 不建议数据库化的内容

首页首版文案建议仍放在前端 i18n 词典中，不进入数据库。

原因：

1. 变更频率不高
2. 首版实现更轻
3. 更适合 Nuxt i18n 直接维护

## 6. 页面实现建议

### 6.1 技术实现

建议：

1. 首页优先 SSR 或静态化输出
2. 首屏图片与文案避免过重
3. CTA 直接链接到注册、登录、激活入口

### 6.2 视觉实现

建议：

1. 延续 `Meouwow` 的高可信、品牌感表达方式
2. 但视觉内容必须围绕“防丢找回”，不能直接照搬宠物品牌文案

## 7. 结论

首页首版不需要重新发明结构，直接借鉴 `Meouwow` 当前首页的信息架构最省时间。

真正要做的是把同样的结构替换成：

1. SmartTag 的品牌语言
2. 防丢找回的核心卖点
3. 丢失模式与隐私模式的清晰说明
