## 2. 总体视觉方向

### 2.1 设计关键词

首页整体视觉继续围绕以下关键词展开：

1. 简约
2. 紧凑
3. 温暖
4. 品牌感
5. 低饱和
6. 可阅读

### 2.2 视觉原则

无论桌面端还是移动端，都建议遵循以下原则：

1. 让 banner 成为情绪入口，而不是功能入口。
2. 让导航保持轻量，不压过首屏。
3. 让每一屏只表达一个核心意思。
4. 让页面通过留白和版式建立节奏，而不是通过大量装饰建立层次。

### 2.3 页面区块顺序

首页区块顺序保持不变：

`Nav + Hero -> Manifesto -> Story Video -> Mission + Values -> Our Story + Footer`

## 3. 桌面端视觉稿说明

### 3.1 总体方向

桌面端建议做成“轻品牌首页”的感觉：

1. 首屏有足够情绪张力
2. 后续区块明显收紧
3. 文字区宽度受控
4. 页面始终保持干净和安静

### 3.2 版心与节奏

建议桌面端视觉稿保持以下节奏：

1. Hero 最宽、最强
2. Manifesto 收窄
3. Story Video 再放开
4. Mission + Values 转为结构型中段
5. Our Story + Footer 平静收尾

说明：

1. 不建议所有区块都使用同一宽度，否则会显得平。
2. 建议通过“宽窄变化”制造阅读节奏。

### 3.3 第一屏：Nav + Hero

#### 3.3.1 视觉目标

桌面端首屏要同时完成三件事：

1. 用 banner 建立情绪
2. 用最少文案完成品牌定调
3. 用轻导航建立秩序

#### 3.3.2 Header 视觉方向

建议：

1. Header 默认透明悬浮在 banner 上。
2. Logo 体量小而稳，不做很重的品牌块。
3. 主导航项控制在 3 个。
4. 语言切换做轻工具化表现。
5. 右侧轻按钮可保留，也可在视觉稿阶段对比“有按钮”和“无按钮”两个版本。

滚动后建议状态：

1. Header 转为浅色半透明 sticky bar。
2. 高度轻微缩小。
3. 字色从浅变深。
4. 底部分隔非常轻，不做强描边。

#### 3.3.3 Hero 视觉方向

建议：

1. 保留当前 banner 图完整情绪。
2. 在图片上叠加暖色透明渐层。
3. 文案块放左侧偏下位置。
4. 右侧和中部尽量让给图像主体。

文案层级建议：

1. Eyebrow 最弱
2. Heading 最强
3. Subheading 次强
4. 按钮最轻

不建议：

1. 不增加第二按钮
2. 不增加指标数字
3. 不增加图标说明

#### 3.3.4 Hero 视觉稿重点

设计稿中需要确认：

1. 文案块是否压到狗猫主体
2. 标题是否足够短
3. 渐层蒙版是否影响图片氛围
4. 首屏是否显得“简洁但不空”

### 3.4 第二屏：Manifesto

#### 3.4.1 视觉目标

这一屏需要让页面从首屏图像过渡到阅读状态，但仍然保持品牌气质。

#### 3.4.2 视觉方向

建议：

1. 采用窄列单栏排版。
2. 标题字号明显小于 Hero 主标题。
3. 正文采用高可读性排版，不装饰过度。
4. 页面背景保持干净，可用极轻底纹或非常浅的色块。

不建议：

1. 不做多栏长文
2. 不做 quote 卡片
3. 不做图文拼贴

#### 3.4.3 视觉稿重点

设计稿中要重点看：

1. 行宽是否舒适
2. 上下留白是否均衡
3. 文字区是否过于靠中导致缺乏秩序

### 3.5 第三屏：Story Video

#### 3.5.1 视觉目标

这一屏需要成为页面中的“情绪停顿点”。

#### 3.5.2 视觉方向

建议：

1. 使用单一大图卡。
2. 图卡比例偏横向。
3. 播放按钮居中或略偏左。
4. 说明文字极短，放在卡片下方或边缘。

图卡气质建议：

1. 圆角有，但不要太软
2. 阴影轻
3. 不要做成重组件感的视频模块

#### 3.5.3 视觉稿重点

设计稿中要重点确认：

1. 图卡是否足够“像品牌内容”，而不是“像播放器”
2. hover 状态是否轻微即可
3. 与前后区块的节奏是否自然

### 3.6 第四屏：Mission + Values

#### 3.6.1 视觉目标

这屏是全页唯一一个结构感略强的区块，但依然不能掉回功能介绍页。

#### 3.6.2 视觉方向

建议：

1. 左栏聚焦主陈述。
2. 右栏以 2 到 3 个轻量 value 项展开。
3. 使用版式差异建立层级，而不是用卡片堆砌。

左栏建议：

1. Heading 稍大
2. Body 保持一段
3. 留白稍多，体现“立意”

右栏建议：

1. 每条 value 单独成组
2. 标题短、解释短
3. 用间距、细线或浅底做最轻分隔

不建议：

1. 不做标准 feature card 三列布局
2. 不做图标 + 标题 + 长描述的产品页结构

#### 3.6.3 视觉稿重点

设计稿中要重点确认：

1. 左右信息密度是否平衡
2. 右栏是否太像卡片列表
3. 中段是否显得过重

### 3.7 第五屏：Our Story + Footer

#### 3.7.1 视觉目标

这一屏要平静结束页面，让用户感觉“读完了”，而不是“还要继续看功能”。

#### 3.7.2 视觉方向

建议：

1. Story 采用单栏居中。
2. 标题和正文的层级比前几屏更收。
3. Closing Statement 可略大，但只作为收束句。
4. Footer 极简，薄，不强调。

Footer 建议：

1. 左边保留品牌名
2. 右边放邮箱、社媒、语言、版权
3. 不做四列站点地图

#### 3.7.3 视觉稿重点

设计稿中要重点确认：

1. Story 到 Footer 的过渡是否自然
2. Footer 是否足够轻
3. 收尾是否安静，而不是营销化

## 4. 移动端视觉稿说明

### 4.1 总体方向

移动端不建议简单缩放桌面端，而应该重新理解“紧凑”的含义：

1. 更短的首屏
2. 更短的文案
3. 更直接的结构
4. 更少的视觉干扰

### 4.2 页面节奏

移动端节奏建议是：

1. 首图建立情绪
2. 文字快速跟进
3. 中间保留一个视频停顿区
4. 内容区尽量单栏
5. 底部轻收尾

### 4.3 第一屏：Nav + Hero

#### 4.3.1 视觉方向

建议：

1. 顶部只保留品牌名和汉堡菜单。
2. Header 高度比桌面端更紧。
3. Hero 图像继续保留主视觉，但总高度压缩。
4. 文案尽量减少为“主标题 + 一句副标题”。
5. CTA 可选，如果保留只能有一个。

菜单展开方向建议：

1. 采用单层抽屉或全屏轻菜单。
2. 菜单项数量不超过 4 个。
3. 语言切换放在菜单底部或顶部工具区。

#### 4.3.2 视觉稿重点

设计稿中要重点确认：

1. 首屏是否过高
2. 头图是否被裁坏
3. 菜单是否足够干净

### 4.4 第二屏：Manifesto

#### 4.4.1 视觉方向

建议：

1. 保持单栏。
2. 文案控制在 2 段以内。
3. 标题与正文层级明显，但不要过大。

#### 4.4.2 视觉稿重点

设计稿中要重点确认：

1. 行长是否舒适
2. 段落间距是否足够
3. 是否出现“文章页感”

### 4.5 第三屏：Story Video

#### 4.5.1 视觉方向

建议：

1. 图卡比例偏纵向或接近方形。
2. 播放按钮居中。
3. 说明文字只保留一句。

#### 4.5.2 视觉稿重点

设计稿中要重点确认：

1. 图卡是否占据过多高度
2. 文案是否足够少
3. 与上下文之间是否形成恰当停顿

### 4.6 第四屏：Mission + Values

#### 4.6.1 视觉方向

建议：

1. Mission 放前，Values 放后。
2. 所有内容统一为单栏。
3. Value 项用轻量分组，不要做重边框卡片。

#### 4.6.2 视觉稿重点

设计稿中要重点确认：

1. 这屏是否过长
2. value 项是否过多
3. 视觉密度是否仍然紧凑

### 4.7 第五屏：Our Story + Footer

#### 4.7.1 视觉方向

建议：

1. Story 保持单栏、短文。
2. Closing Statement 放在正文后，稍放大。
3. Footer 竖向堆叠，但不拉高。

#### 4.7.2 视觉稿重点

设计稿中要重点确认：

1. Story 是否足够短
2. Footer 是否太像站点地图
3. 页面是否平静结束

## 5. 关键状态说明

### 5.1 Header 状态

建议至少在视觉稿中展示两个状态：

1. 首屏透明态
2. 滚动后 sticky 态

### 5.2 按钮状态

建议展示：

1. 默认态
2. hover 态
3. 按下态，可选

要求：

1. 状态差异要轻
2. 不做夸张动效

### 5.3 Video Card 状态

建议展示：

1. 默认态
2. hover 态

要求：

1. 只做轻微层次变化
2. 不做播放器式复杂控件

### 5.4 Mobile Menu 状态

建议展示：

1. 收起态
2. 展开态

要求：

1. 菜单背景干净
2. 菜单结构单层
3. 不做二级展开

## 6. 配色与材质建议

### 6.1 配色方向

建议延续前文确定的低饱和暖色路线：

1. 奶油白
2. 暖灰
3. 浅橄榄绿
4. 棕金点缀
5. 深灰文本

### 6.2 材质建议

建议：

1. 浅透层
2. 轻毛玻璃
3. 很浅的边界阴影
4. 细腻而非强烈的图层关系

不建议：

1. 高对比玻璃拟态
2. 重投影
3. 高饱和渐变

## 7. 视觉稿检查清单

在出稿或评审时，建议按以下问题检查：

1. 桌面端是否有清晰的宽窄节奏变化
2. 移动端是否不是桌面端的机械缩放
3. 导航是否轻，且不喧宾夺主
4. Hero 是否保住 banner 的温暖氛围
5. 页面是否仍然控制在 5 个核心区块
6. 中段 Mission + Values 是否保持品牌表达，而非功能解释
7. Footer 是否足够薄，结尾是否自然

## 8. 下一步建议

在本视觉稿说明确认后，可继续推进以下任一步骤：

1. 出首页视觉稿
2. 出桌面端高保真稿
3. 出移动端高保真稿
4. 视觉稿确认后进入 `pages/index.vue` 改版实现
